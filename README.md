
# DDJ-FLX6 Alternate Mapping for Rekordbox

Adds new and otherwise unavailable features to existing buttons/knobs for the Pioneer DJ DDJ-FLX6


## Features

- MergeFX ON/OFF -> Play/Pause Deck 3/4
- MergeFX Parameter -> JogPitchBend Deck 3/4


## Planned Features

- Further MergeFX Mappings
- JogCutter Remap

## Notes

- MergeFX JogPitchBend is the reverse of usual jog nudging - rotate clockwise for slower speed, rotate anti-clockwise for faster speed
- JogIndicator of Deck 1 appears to occasionally glitch and show 12 o'clock position for split second
## Installation

Go to your Rekordbox Midi Mapping location

Usually:

```bash
C:\Program Files\rekordbox\rekordbox x.x.x\MidiMappings
```
Delete the DDJ-FLX6.midi.csv file

Paste the downloaded alternate map in the folder and launch Rekordbox

To 100% confirm it's working, click on the "Midi" tab at the top of the screen, go to "Import", then select the newly downloaded file from the MidiMappings folder

Enjoy!
